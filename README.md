# Casa — interface para Hisense VIDAA

Protótipo de tela inicial em HTML, CSS e JavaScript, pensado para navegação com as setas e o botão OK do controle remoto.

## Publicação

O projeto pode ser publicado pelo GitHub Pages a partir da raiz do repositório. A página publicada fica acessível publicamente pela internet. Os arquivos deste protótipo não contêm identificadores da TV, PINs, endereços da rede doméstica nem credenciais.

## Estado atual

- Navegação visual entre Início, Filmes, Séries, Música e Apps.
- Destaque de foco para controle direcional.
- Cartões de exemplo; ainda não iniciam os aplicativos nativos da TV.
- Sem bibliotecas externas, fontes remotas, analytics ou chamadas de API.
